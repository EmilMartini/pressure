Pressure: sound effects and ambience
=====================================

Every file in this folder is cut, layered, filtered, levelled and re-encoded (ffmpeg,
Ogg Vorbis, mono 44.1 kHz for effects, 22 kHz for footsteps and drips, stereo 32 kHz for
the ambient beds) from the sources below. No generative AI was used. All sources are
CC0 1.0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/):
no attribution is required, but the authors are credited here anyway, and a few asked
for it as a courtesy. Licences were read on each source's page (OpenGameArt licence
field) or in the pack's own License.txt (Kenney), on 2026-11-05.

The design table that maps sources to game files (offsets, layers, filters) lives with
the build script used to make them; the game-side names are in scripts/sfx.gd (BANK).
